PORTOFOLIO FRONTLINER - PETUNJUK PENGGUNAAN

ISI FOLDER
- index.html  : struktur dan isi website
- style.css   : desain, warna, dan tampilan responsif
- script.js   : menu navigasi dan tahun otomatis
- foto-profil.jpg : tambahkan foto formal Anda dengan nama file ini

CARA MEMBUKA DI VS CODE
1. Ekstrak file ZIP.
2. Buka Visual Studio Code.
3. Pilih File > Open Folder, lalu pilih folder portofolio_frontliner.
4. Buka index.html di browser. Disarankan memasang ekstensi "Live Server" di VS Code,
   lalu klik kanan index.html > Open with Live Server.

SEBELUM DIPUBLIKASIKAN, GANTI BAGIAN BERIKUT DI index.html:
- Nama Lengkap
- Foto profil (simpan foto sebagai foto-profil.jpg di folder yang sama)
- Tanggal pengalaman kerja dan magang
- Nama instansi/perusahaan tempat magang
- Nama universitas dan tahun pendidikan
- Email, nomor WhatsApp, dan domisili
- Isi kemampuan sesuai kemampuan yang benar-benar Anda miliki

CATATAN
- Hapus poin tugas yang tidak sesuai dengan pekerjaan yang benar-benar pernah dilakukan.
- Jangan unggah catatan transaksi atau data keuangan asli toko.
- Gunakan foto dan informasi kontak yang memang ingin dibagikan kepada perekrut.

CARA MEMBUAT WEBSITE ONLINE DENGAN GITHUB PAGES
1. Buat akun atau masuk ke https://github.com/
2. Buat repository baru, misalnya "portofolio-frontliner".
3. Unggah index.html, style.css, script.js, foto-profil.jpg, dan README.txt.
4. Buka Settings > Pages.
5. Pada bagian Build and deployment, pilih Deploy from a branch.
6. Pilih branch main dan folder /(root), lalu Save.
7. Tunggu proses publikasi selesai. GitHub akan memberikan alamat website yang dapat dibagikan.

Alternatif hosting: Netlify (https://www.netlify.com/)
Anda dapat mengunggah folder website melalui fitur deploy manual Netlify.
